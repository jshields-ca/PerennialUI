None yet.

## Fonts

All under the SIL Open Font License 1.1, unmodified, in `PerennialUI/Media/Fonts/` with each licence text beside the font.

| Name | File | Licence | Source |
| --- | --- | --- | --- |
| Sora (Bold) | `Sora-Bold.ttf` | OFL 1.1, `Sora-OFL.txt` | [sora-xor/sora-font](https://github.com/sora-xor/sora-font) at commit `7f9a9c5` |
| DM Sans (Medium) | `DMSans-Medium.ttf` | OFL 1.1, `DMSans-OFL.txt` | [googlefonts/dm-fonts](https://github.com/googlefonts/dm-fonts) at commit `d0520ba` |
| DM Mono (Medium) | `DMMono-Medium.ttf` | OFL 1.1, `DMMono-OFL.txt` | [google/fonts](https://github.com/google/fonts/tree/main/ofl/dmmono) |

These fonts cover Latin scripts only. On Russian, Korean and Chinese clients the UI uses the fonts that ship with the game and does not redistribute them.

## Textures and other media

No third-party media. The panel textures in `PerennialUI/Media/Textures/` are generated by `tools/make-textures.js` and the artwork in `branding/` was drawn for this project; both are licensed with the rest of the repository.
